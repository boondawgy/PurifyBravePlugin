PLEX → PURIFIER

Purify for Plex

Send a movie to your Purifier queue from the P button on its poster. An up arrow means sent or queued, a blue circle means processing, a green check means processing completed, and a red ! means failed (click to retry).

Used when its server ID matches the selected movie. Other servers are discovered through your Plex account.

Stored locally in this extension. Sent only to Plex. Find your token.

File path mapping

Default: /Volumes/Media/Media/Movies/Film.mp4 → /media/Movies/Film.mp4. Prefix matching is case sensitive. Paths outside this prefix are rejected.

Purifier must have a saved profile named Movie. Requests contain file_path, profile, and title.

Status path matching

If Purifier processed files in a staging folder before exporting them into Plex’s library, map that source prefix to the library prefix here. Matching keeps the entire relative file path. This affects status matching only.

Example: /processing/Movies/Film.mp4 matches /media/Movies/Film.mp4. Use the Purifier-side library prefix after the Plex file path mapping above. Leave both blank to disable.

Status refresh

Default: once a day. Turning automatic refresh off keeps the saved indicators until you refresh manually. Sending a movie always updates its indicator immediately.

Refreshes Purifier’s saved job status for all open Plex tabs. Save settings before refreshing. Cached status is shared across tabs and survives browser restarts; failed refreshes keep the last known status.
